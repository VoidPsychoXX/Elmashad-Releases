## Requirements

- Windows 10 or 11
- Microsoft Excel 2021, 2024 or Microsoft 365 (64-bit recommended)
- .NET Framework 4.8 (installed on up-to-date Windows by default)

## Installation

1. **Download** the Elmashad installer (Stable or Beta).
2. **Close** Excel.
3. **Run** the installer — no administrator account needed.
4. **Open** Excel.
5. Click the **Elmashad-P6** or **Elmashad-ExcelTool** ribbon tab.

## Automatic Updates

Elmashad keeps itself up to date:

- New versions are checked automatically, in the background.
- When an update is available, Elmashad tells you — it never interrupts your
  work.
- The update installs safely **after you close Excel**.
- You do not need to reinstall Elmashad manually for normal updates.

## What's inside

**Elmashad-P6 — Planning & Primavera**

- **Open XER** — parse a Primavera P6 schedule completely, read-only.
- **Dashboard** — the project overview: dates, counts, critical activities.
- **Project Data** — browse activities, WBS, relationships, calendars,
  resources and expenses; export any table into the workbook.
- **Schedule Health** — DCMA-style checks with drill-down and export.
- **WBS tools** — Color by WBS, WBS to HTML, HTML Dashboard.

**Elmashad-ExcelTool — Everyday Excel productivity**

- **Quick Clean** — clean pasted-data problems in the selected cells
  (preview first, formulas protected).
- **Workbook Audit** — one-click workbook health check: formula errors,
  broken formula patterns, data-quality, structure and performance issues.
  Read-only: it finds problems, it never changes your workbook.

**General** — Settings (Light/Dark/System themes), Updates, Logs, About.
